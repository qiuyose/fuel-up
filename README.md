# Fuel Up - 极简个人加油记录 (iOS PWA)

专为 iPhone 打造的个人极简加油记录软件，纯前端架构，无需购买苹果开发者账号，无需复杂环境，开箱即用。

---

## 🌟 核心特性与流程

1. **自动显示日期与 GPS 定位：**
   - 进站打开软件，自动显示今日日期；
   - 自动调用手机 GPS 获取当前位置与周边加油站名称，支持一键点击修改。

2. **仪表盘里程采集（拍照/手动）：**
   - 点击“拍仪表盘”直接调用 iPhone 相机拍摄汽车里程表；
   - 支持 AI 视觉自动识别里程数字，或直接输入；
   - 照片在本地自动轻量压缩留存，不占手机内存。

3. **油品标号与加油机数据：**
   - 92# / 95# / 98# / 0#柴油 快捷一键切换；
   - 点击“拍加油机”拍摄加油机液晶屏；
   - **智能联动计算**：输入金额与单价自动算升数，或输入升数自动算金额。

4. **实用核心指标自动核算：**
   - **区间行驶续航**：自动计算自上次加油以来跑了多少公里（本次里程 - 上次里程）；
   - **真实百公里油耗**：支持“是否加满（跳枪）”开关，满油状态下根据真实加油升数精确核算百公里油耗；
   - **每公里用车成本**：清晰掌握每公里花几毛钱；
   - **优惠实付记录**：如有满减优惠可记录实付金额，算出实际每升便宜了多少。

5. **数据安全与离线支持：**
   - 数据完全保存在自己手机本地（Local Storage），隐私无忧；
   - 配备 Service Worker 离线缓存，加油站地下室或没信号也能流畅秒开记账；
   - 支持一键导出 CSV 表格（可用 Excel / 苹果 Numbers 打开）与 JSON 备份包。

## 🚀 如何在 iPhone 上使用（添加到桌面 App）

### 方式一：电脑与 iPhone 在同一个 Wi-Fi（局域网极速体验）
1. 在电脑上的 `E:\软件\Fuel Up` 目录下，用命令行启动一个本地服务：
   ```bash
   npx serve -l 3000
   ```
2. 查看电脑的局域网 IP（比如 `192.168.1.5:3000`）；
3. 用 iPhone 的 Safari 浏览器打开这个地址；
4. 点击底部的 **“分享”** 按钮（方框带向上箭头） $\rightarrow$ 往下滑点击 **“添加到主屏幕”**。

### 方式二：部署到公网（永久免费，任何地方可用，最推荐）
1. 把本项目文件夹上传到你的 GitHub 仓库；
2. 登录免费的 **Vercel** (https://vercel.com) 或 **Cloudflare Pages**；
3. 点击“Import Project”，选择该仓库，点击 Deploy；
4. 获得一个专属网址（如 `https://my-fuel-up.vercel.app`）；
5. 用 iPhone Safari 打开该网址 $\rightarrow$ 分享 $\rightarrow$ **添加到主屏幕**，完成！
