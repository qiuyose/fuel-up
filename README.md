# Fuel Up - 极简个人加油记录 (iOS PWA)

专为 iPhone 打造的个人极简加油记录软件，纯前端架构，无需购买苹果开发者账号，无需复杂环境，开箱即用。

---

## 🌟 核心特性与流程

1. **自动显示日期与 GPS 定位：**
   - 进站打开软件，自动显示今日日期；
   - 自动调用手机 GPS 获取当前位置与周边加油站名称，支持一键点击修改。

2. **仪表盘里程采集（拍照/手动）：**
   - 点击“拍仪表盘”直接调用 iPhone 相机拍摄汽车里程表；
   - 支持 AI 视觉自动识别里程数字，或直接输入；
   - 照片在本地自动轻量压缩留存，支持全屏无损预览。

3. **油品标号与加油机数据：**
   - 92# / 95# / 98# / 0#柴油 快捷一键切换；
   - 点击“拍加油机”拍摄加油机液晶屏，AI 智能提取金额、升数与单价；
   - **高精度同步**：加油金额与升数展示均精确到小数点后两位（如 `¥350.25`、`42.36L`），与加油机实际计量完全同步；
   - **智能联动计算**：输入金额与单价自动算升数，或输入升数自动算金额。

4. **实用核心指标自动核算：**
   - **区间行驶续航**：自动计算自上次加油以来跑了多少公里（本次里程 - 上次里程）；
   - **真实百公里油耗**：支持“是否加满（跳枪）”开关，满油状态下根据真实加油升数精确核算百公里油耗；
   - **每公里用车成本**：清晰掌握每公里花几毛钱；
   - **优惠实付记录**：如有满减优惠可记录实付金额，算出实际每升便宜了多少。

5. **大容量存储、云端同步与离线支持：**
   - **IndexedDB 大容量存储**：升级为原生 IndexedDB 数据库引擎，彻底突破浏览器 5MB 存储瓶颈（数百 MB 可用配额），海量照片与数年历史记录长效存储无忧；
   - **旧版数据无缝迁移**：应用启动时自动检测并将旧版 LocalStorage 记录搬运至 IndexedDB，无损平滑过渡；
   - **双轨容灾机制**：IndexedDB 主存 + 本地镜像双重保障；
   - **GitHub Gist 自动云端同步**：支持私有 Gist 自动静默备份，换新手机时一键“从云端拉取恢复”即可 100% 还原所有历史与凭证照片；
   - **同步状态完整可视**：配置界面同步时间精确显示年月日（如 `2026/11/17 11:28`）；
   - **离线秒开**：配备 Service Worker 离线缓存，地库断网也能流畅记账，联网后自动补传；
   - **数据自由导出**：支持一键导出 CSV 表格（可用 Excel / 苹果 Numbers 打开）与 JSON 完整备份包。

## 🚀 如何在 iPhone 上使用（添加到桌面 App）

### 方式一：电脑与 iPhone 在同一个 Wi-Fi（局域网极速体验）
1. 在电脑上的 `E:\软件\Fuel Up` 目录下，用命令行启动一个本地服务：
   ```bash
   npx serve -l 3000
   ```
2. 查看电脑的局域网 IP（比如 `192.168.1.5:3000`）；
3. 用 iPhone 的 Safari 浏览器打开这个地址；
4. 点击底部的 **“分享”** 按钮（方框带向上箭头） $\rightarrow$ 往下滑点击 **“添加到主屏幕”**。

### 方式二：部署到公网（永久免费，任何地方可用，最推荐）
1. 把本项目文件上传到你的 GitHub 仓库；
2. 登录免费的 **Vercel** (https://vercel.com) 或 **Cloudflare Pages**；
3. 点击“Import Project”，选择该仓库，点击 Deploy；
4. 获得一个专属网址（如 `https://my-fuel-up.vercel.app`）；
5. 用 iPhone Safari 打开该网址 $\rightarrow$ 分享 $\rightarrow$ **添加到主屏幕**，完成！

## 🎨 iOS 专属 App 图标设计 (Fuel Up Icon)

针对苹果 iOS 人机交互指南 (HIG) 与 iPhone Super Retina 屏幕专属重绘：
- **设计理念**：
  - **曜黑钛金底座**：深邃高级质感，在 iPhone OLED 屏幕及各类壁纸上视觉对比极强；
  - **现代智能加油机**：纯白陶瓷大圆角流线机身与黑曜石液晶仪表，一眼辨识“加油记账”属性；
  - **汽车动态油耗仪表**：液晶屏内呈现由冷青到金黄直达满油高亮翡翠绿（FULL / 50L）的动态弧线；
  - **Fuel Up 跃升能量油滴**：机身上方悬浮一颗晶莹剔透的琥珀金能量水滴，内嵌纯白向上发光箭头（↑），完美契合“Fuel Up（加满油·更省心）”的核心寓意。
- **全套尺寸规格**：
  - `apple-touch-icon.png` (180x180): 苹果 Safari 添加到主屏幕标准尺寸；
  - `icon-192.png` & `icon-512.png`: 现代 PWA 标准高清图标；
  - `icon.svg`: 高保真无损矢量原稿；
  - 附带备用版 `apple-touch-icon-sunset.png` / `icon-sunset.svg`（日落活力燃橙版），可按喜好切换。
